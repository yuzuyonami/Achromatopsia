# Achromatopsia
Focusing purely on the core structure. Monorepo &amp; build orchestrator for KOBI.
 
---

## ⚙️ System Components
- **`Kobi Build System`** — Custom SCons orchestration for automated builds.
- **`Kobi Internal System`** — Private core logic and execution engine.
- **`Achromatopsia Runtime`** — Low-overhead pipeline for system integration.
